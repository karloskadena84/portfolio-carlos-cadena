# Carlos Cadena — Portafolio

Portafolio personal (React + Vite + Tailwind + GSAP + Framer Motion).

## Local

```bash
npm install
npm run dev
```

## Deploy (Vercel)

1. Entra a https://vercel.com/new
2. Importa este repo `karloskadena84/portfolio-carlos-cadena`
3. Framework: Vite — Build: `npm run build` — Output: `dist`
4. Deploy

URL del repo: https://github.com/karloskadena84/portfolio-carlos-cadena
